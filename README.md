# BlackJack Vite

Pasos descargar y ejecutar el proyecto:

1. Clonar el repositorio
2. Ejecutar `npm install` para reconstruir los módulos de node
3. Levantar el devServer (bajo node.js) `npm run dev`
4. Abrir el proyecto en el `localhost:....`

## Generar archivo de producción

1. Ejecutar `npm run build`
2. Tomar la carpeta `dist` y subirla al servidor
